# Seeklight-Investigation

Materials, notes, and working files related to the investigation of [Seeklight](https://seeklight.io/) and its eventual integration with [DART (Digital Archivist's Resource Tool)](https://aptrust.github.io/dart-docs/) at Grinnell College Libraries.

## Purpose

This repository serves as a central location for:

- Research and evaluation notes on Seeklight as a discovery/search platform
- Technical findings from hands-on investigation
- Documentation of the integration path between Seeklight and DART
- Configuration examples, scripts, and supporting files

## Directory Structure

```
.
├── investigation/       # Notes and findings from Seeklight evaluation
│   └── notes/           # Meeting notes, observations, and analysis
├── dart-integration/    # Work related to DART ↔ Seeklight integration
│   ├── config/          # Sample or draft configuration files
│   └── scripts/         # Helper scripts for integration tasks
└── resources/           # Reference materials, links, and background documents
```

## Background

**Seeklight** is a search and discovery platform. Grinnell College Libraries is exploring its potential for surfacing digital collections content.

**DART** (Digital Archivist's Resource Tool) is an open-source tool developed by APTrust for packaging and uploading digital preservation content. Integrating DART's outputs with a Seeklight-based discovery layer is the eventual goal of this investigation.
